**Scope:** what the blog is about, and topics that are on hold.

## Where drafts go

- Folder: `docs/blog/`
- File name: `YYYY-MM-DD-<slug>.blog.md`

## Frontmatter

List the fields your CMS or static site generator reads.

## Titles

How titles are chosen (default: Claude offers two to four, the owner picks), length, and any words a title must never start with.

## Tags

The allowed tags, lowercase, one or two per post. Reuse before you invent.

## Voice

The reference post to match, and whether the blog says "I" or "we". As the owner edits drafts, write their style down here: what they always change is the best guide for the next draft.

## Code

How often posts show code (default: only where there is a real lesson, and many posts have none).

## Extra redaction

Anything specific to this project that must never appear (in addition to the skill's checklist).

## Upload

The command that uploads a draft, if any, and the rule: drafts only, ask first, never overwrite a draft already in the CMS. Also how to read a post back (to pull the owner's edits into the file after they publish).
