# Changelog

## 0.2.0 (unreleased)

- New text pattern 10, unchecked specifics: a precise number, date, quote or feature nobody looked up. Writing now checks every specific it keeps.
- The read-aloud test, in `patterns.md` and in the write mode.
- Review starts with five questions: what it's for, which claims hold, whether it could be swapped into an unrelated product, what's missing, and what to cut first.
- New design pattern 10, things that look like they work and don't, and a check that clicks every control once.

## 0.1.0 (unreleased)

- First version: a library of nine kinds of text slop (`patterns.md`), a grouped word list with plain swaps (`words.md`), slop-to-better pairs for eleven genres (`genres.md`) and nine kinds of design slop with the checks to run (`design.md`).
- Two modes: write it right the first time, or review a draft.
- Off switch: `non-slop: off` in the project's `CLAUDE.md`.
