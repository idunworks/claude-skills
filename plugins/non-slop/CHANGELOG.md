# Changelog

## 0.1.0 (unreleased)

- First version: a library of nine kinds of text slop (`patterns.md`), a grouped word list with plain swaps (`words.md`), slop-to-better pairs for eleven genres (`genres.md`) and nine kinds of design slop with the checks to run (`design.md`).
- Two modes: write it right the first time, or review a draft.
- Off switch: `non-slop: off` in the project's `CLAUDE.md`.
